## 真正值得留下的认识

**保留作者原意：** 作者是在连贯走势中解释资金行为：放量上影暴露卖盘，后续没有明显坍塌使他倾向于试盘解释；整理中的连续阴线、支撑附近的回撤与再次放量被他理解为卖压释放，随后再观察突破、底仓与回踩。他并非只凭一根放量K线立即判断买点，也没有把缩量回撤规定为唯一途径。这里保留他的试盘、卖压释放与资金行为解释，再区分其中哪些能够直接计算、哪些仍需验证。以下方法是助手的操作化改写，不是作者完整交易法的逐条复刻。

一次放量只能说明交易活动增加。更有信息量的是随后价格怎样响应：同样的成交量，价格持续破位与价格守住关键区域，意味着两种不同的观察结果。先标记异常，再跟踪响应，最后核对结构是否重新转强，比把一根K线直接贴上买点标签更容易验证。

候选池也应按证据成熟度管理：发现异常→等待守位→核对再突破→形成条件计划→复盘结果。进入候选池与决定参与之间应保留明确距离。

## 必须修正的推理

1. **后来上涨不能证明当初是谁在试盘。** 交易活跃、价格守位和再突破是可观察现象；庄家身份、持仓成本与主动洗盘意图是解释假设。普通OHLCV不能识别实际资金身份。市场整体反弹、消息变化或其他参与者承接也能产生相似图形。
2. **放量下跌不必然有利。** 它也可能对应持续卖出、基本面恶化或流动性压力。必须同时检查收盘位置、后续是否继续破位以及市场环境；不能仅凭成交量把下跌定义为洗盘。
3. **不能用完整未来图形制造早期信号。** 视频采用后续走势反推早期含义。用于学习可以更新解释，用于工具则必须逐日保存当时知道什么、何时达到条件，不能把后来确认的标签追写成当初已经确认。
4. **成功图例不是效果统计。** 本次仅核对一个展示案例，没有失败样本、统一筛选门槛、明确退出条件或收益检验。标题中的涨停效果不能据此推广。

## 候选方法：放量—守位—再确认

以下是助手根据视频改写的观察流程，不是作者原有完整规则，也不是用户已采用的纪律。

| 阶段 | 核对什么 | 允许形成的结论 |
| --- | --- | --- |
| 环境 | 周线大方向、日线结构、大盘与板块；数据是否完整 | 决定观察背景，弱势环境单独标记 |
| 放量事件 | 相对前期成交量、实体与上下影、所处位置 | 交易活动异常，收入候选池 |
| 守位整理 | 当时已知的支撑区、回撤深度、收盘位置、整理时间 | 守位中、失守或到期；不命名庄家成本 |
| 回撤核对 | 缩量与放量回撤分别记录；是否有承接及后续破位 | 卖压减轻、承接待确认或结构恶化的候选解释 |
| 再次确认 | 收盘越过已确定压力区、量价响应、后续回踩 | 突破待确认、观察条件满足或突破失败 |
| 计划与回看 | 事前风险、退出条件、实际执行、后续结果 | 保留支持与反例，调整候选方法 |

**画线原则：** 在事件首次出现时，只用此前完成K线确定原有支撑和压力。事件后新形成的区间只能从形成当天开始引用，并记录版本。支撑用区域表达；穿越幅度与收回期限需要预先配置，不能跌破后随意下移。

**失效与到期：** 预定支撑失守且未在约定期限收回；突破后跌回原区间且继续转弱；观察期内始终没有进一步确认；行情缺失或单位、复权不一致。分别标记失效、到期或无法判断，不无限期解释成蓄势。

**风险处理：** 任何真实参与前，独立写清观察周期、账户承受范围、拟参与比例、失效后的处理和交易约束。本次不指定个人仓位、不自动下单、不创建虚构交易或实践结果。

**仍待验证：** 哪些趋势背景适用；放量基准与门槛；守位期限和容差；缩量回撤与放量承接是否分别有效；单次突破和回踩确认的差异；与不筛选时的基准结果相比是否改善。

## 工具沉淀：一条可复用的观察链

现有大趋势分析、自动画线、量价参与分析可以提供背景和辅助证据；2026-10-07继续开发后，已接通首版“放量后的结构观察”：日线事件识别、冻结参考价区、自动画线、逐日阶段回看与共享工具调用。以下保留完整规格；独立持久候选池、完整回测和后台扫描尚未实现。逐日回看使用当前来源的历史序列截取日期，并非当时真实保存的事前快照。

首版使用此前20根量的中位数、默认2倍放量门槛、上影占振幅20%、至少3根连续区内守位后核对再次突破、默认20根观察期限；门槛与期限可调整。参考区取事件低点与高点，容差按事件前14根波幅计算。突破先检查收盘及量能，再等后续完成日线守住；连续阴线、触区守位和回踩分别显示。**这些是实现参数与代理条件，视频未明确给出；事件高低点不能冒称为作者全部手工支撑/成本区，也没有复刻筹码分布。**

### 1. 放量事件定位

输入：证券、周期、截止时点、已完成OHLCV、来源与复权信息、基准窗口和相对量阈值。

计算：事件量÷此前窗口的成交量中位数，分母不含事件自身；实体、影线和收盘在当根振幅中的位置。分钟线需要可比时段基准，不能直接套用日线成交量门槛。零量、停牌、缺失数据不能填零参与计算。

输出：事件日期、相对量、K线形态、与此前支撑/压力的关系、数据质量。标记“放量事件”，不自动输出“试盘”或“主力入场”。

### 2. 守位与回撤检查

输入：事件、事件当时冻结的价区、容差、期限和截至当前可见的数据。

输出：守位中、已失守、已到期或数据不足；最大回撤、价区穿越、收盘表现、缩量回撤/放量回撤分类。自动叠加事件线、支撑区域、压力区域和观察期限；每条线说明来源日期和当时依据。

### 3. 二次突破核对

输入：已形成且冻结的整理区间、收盘突破门槛、量能条件、后续确认方式。

输出：未突破、突破待确认、确认条件满足、突破失败。显示哪些条件已满足、哪些尚缺，以及会使当前结论失效的具体条件。确认需要后续K线时，当前状态必须保持待确认，不能提前画成成功。

### 4. 候选池与方法复盘

按候选、守位、待确认、观察条件满足、失效、到期管理。状态变化保存日期、输入快照、参数和方法版本。提供“按当时看到的数据回放”，完整保留失败与到期案例。

回看至少比较：不同趋势背景、不同参数、确认前后差异及未筛选基准；同时报告样本数和缺失情况。样本收益需明确测量时点、成本与可成交限制。未经检验不输出胜率或预期收益，不开启后台扫描和通知。
