# 图表与资金工具

入口：交易体系 → 器 · 交易工具。网页和手机网页共用同一套实现；本轮未构建或调试小程序。

## 自动画线与模式推荐

载入行情后默认开启自动画线，选择观察范围（40、80、160根）会重新匹配推荐与线条。可跟随推荐，或切换到另一个有足够依据的模式；依据不足的模式不会强行生成。所有模式使用当前周期、当前观察窗口，窗口之外的未来数据不参与判断。

- **趋势通道**：收盘价最小二乘拟合，R²≥0.50且拟合位移≥3倍近期平均真实波幅时可用。上下沿使用低/高价对拟合中线残差的10%/90%分位。它是统计通道，允许个别极端K线超出，并非连接已确认转折点的传统趋势线。
- **横盘区间**：R²<0.35、区间宽度≤8倍近期波幅，上下沿附近分别至少有2次已确认转折。边界使用此前K线低/高价10%/90%分位，最新收盘单独检查是否离开区间。
- **关键价位**：左右各2根K线确认局部高低点，聚合价差≤1.2倍近期波幅的转折点，重复点至少间隔4根。取最接近最新收盘的最多4组价位。最后2根不确认新转折；后续K线到来可能改变候选结果。

推荐按“趋势通道 → 横盘区间 → 关键价位”逐项检查，均不成立时显示依据不足。少于24根、价格几乎不变、存在明显跳空时暂不自动画线。跳空需要核对除权或事件，本版不做结构分段。近期波幅使用近14根平均真实波幅；横盘最新收盘容差0.6倍波幅，边沿转折容差0.7倍波幅。

蓝色线条为自动候选，金色为个人标注。自动候选不会自动写入资料；“保存为我的标注”保留当前线条，并记录算法版本、模式、观察范围和行情截至时间。以后重新载入，保存线条保留，自动层按最新数据重新分析。可隐藏自动层，再手动补充。讨论草稿包含自动推荐与依据、所选模式、自动线及个人标注。

阈值为本应用的启发式规则，未进行收益回测或胜率验证；R²不表示预测正确率。候选不自动变成纪律，不识别缠论笔或中枢，不外推未来价格。支持阻力和趋势的概念参考 [StockCharts支持阻力说明](https://chartschool.stockcharts.com/table-of-contents/chart-analysis/support-and-resistance) 与 [趋势线说明](https://chartschool.stockcharts.com/table-of-contents/chart-analysis/trend-lines)；上述具体算法和阈值为本应用实现。

## 图表与画线

输入股票名称或代码后载入公开行情。支持日线和5、15、30、60分钟线，使用已完成K线、不复权，最多240根。数据截至时间、来源和获取时间均显示在工具中。

- 查看：点选K线查看开高低收，电脑可移动鼠标查看。
- 水平线：点击关键价位，或输入精确价格。
- 趋势线：依次点击两个位置。
- 价格区间：依次点击两个对角位置；这是个人手绘区间，不自动认定为缠论中枢。
- 标注可写备注、移除、撤销最后一笔。点击“保存标注”后按证券、周期保存，再次载入可恢复。改变股票、周期或关闭工具前会提醒未保存修改；直接刷新页面可能丢失未保存内容。
- 40、80、160、240根控制展示范围，“更早/更新”查看历史窗口。趋势线或区间的端点不在窗口内时暂不显示，可扩大范围找回；标注记录时间与价格。

标注在专用 `runtime/chart-annotations.sqlite` 中保存，备份命令一并备份。云端和本机资料彼此独立；跨设备恢复需访问同一云端应用。多端版本冲突会提示重新载入，避免直接覆盖旧标注。

## 资金参与判断

载入行情后，先自动呈现参与变化、活跃程度和量价方向，再展示指标。至少26根完整K线且成交量有效时才综合判断；最近5根明显跳空（超过3倍平均真实波幅或上一收盘10%，取较大者）时暂停综合判断，先核对除权与事件。

- **参与变化**：近5根平均量相对此前20根≥1.2倍，且至少3根同样放量，才描述为持续放量。最新单根相对量≥1.5倍但持续条件不足时，描述为持续性待确认。
- **活跃程度**：按近5根平均量比值分为较高（≥1.8）、有所增强（≥1.2）、偏低（<0.8）和常态。它不是主力仓位或净买入规模。
- **量价方向**：CMF20≥0.1、近5根涨价、上涨K线量占比≥55%三项同时成立才描述偏买方；CMF≤−0.1、跌价、上涨量占比≤45%同时成立才描述偏卖方，其余保留不明确。

自动模式按优先级比较：卖压增强、量价分歧、放量突破、持续参与、缩量回落、基础观察。多个模式可以同时满足，首个匹配为默认推荐。可切换查看其他模式，未触发时明确标注，并呈现该模式需要的条件。

放量突破要求最新完整收盘越过此前20根最高价、最新相对量≥1.5；持续参与要求持续放量条件成立；缩量回落要求近5根相对均量<0.8且价格回落。卖压增强与量价分歧单独展示，避免把下跌放量直接理解为买入。每个模式给出下一步观察条件，另列新闻、市场波动、换手及散户交易等竞争解释。

主力／庄家身份始终标注无法确认，未接入逐笔成交、委托及持有人身份数据；没有持续放量也不能排除主力参与。当前采用量价启发式判断，未验证胜率。分钟周期未进行日内时段量能归一化。CMF依据参考 [Chaikin原理说明](https://help.chaikinanalytics.com/knowledge-center/chaikin-money-flow)，该指标本身并非直接观察机构订单流；具体5根/20根阈值为本应用实现。

共享工具 `market_study` 返回 `activity.participation`，包含判定、模式、依据、竞争解释、下一步、参数、版本与截至时间。讨论草稿保留这些信息，查询不写入交易事实。


展示四项可核对的量价观察：

| 指标 | 含义 |
| --- | --- |
| 最新相对量 | 最新完整K线成交量 / 此前20根均量 |
| CMF20 | 近20根成交量加权的收盘位置，范围通常为−1到1 |
| 上涨K线量占比 | 收盘高于前一根的K线成交量，占近20根总量的比例 |
| 近20根价格变化 | 最新收盘相对20根以前收盘的变化 |

还提供量价文字观察、CMF走势、完整计算说明和来源。CMF公式参考 [StockCharts ChartSchool](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/chaikin-money-flow-cmf)。跳空时收盘位置与涨跌方向可能不同。

目前未接入逐笔资金净流入，不识别投资者身份。上涨K线量占比不是主动买入比例。成交量单位未标准化，仅在同一来源、同一周期内比较；不输出绝对股数或净流入金额。样本不足、成交量缺失或异常时如实显示不可计算；公开行情可能延迟，交易日历与序列完整性未独立核验。除权附近需另行核对。

## 工具与伙伴协作

“带着这张图与伙伴讨论”会先保存修改，再生成可编辑的对话草稿，包含证券、周期、数据时间、来源、指标与标注，不会自动发送。伙伴可比较其他解释与待验证条件；这些观察不自动成为交易准则。

底层 `market_study` 为只读共享工具，网页、MCP及技能驱动的伙伴都可调用；查询不写入交易记忆。图表标注由本人在网页保存。
