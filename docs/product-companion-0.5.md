# 0.5.0：有积累、有专长、能校正的个人伙伴

2026-10-04。沿用 [日常学习与交易体系主线](product-growth-blueprint.md)，这一版把界面、历史积累、实际协作和使用反馈接起来。网页与手机网页使用同一份源码；小程序按用户安排暂停调试和发布。

## 日常使用

工作台从一个问题开始，也可以直接用文字、录音、图片或文件随手记录。持续讨论在同一个专题进行，已有正文、原始来源与相关经历会带入上下文。

知识库分为学习专题、知识笔记、观察与复盘。笔记可以按自己写的、历史整理、经典导读筛选；来源和版本保留在阅读页。经典按生活与交易边界、判断与执行、方法检验、短线心法四个方向组织。原话、项目解释、个人认同和实际效果分别处理，不以名言替代证据。

交易体系仍以个人内容为中心：交易手册、个人方法、纪律修订和工具箱。历史自述整理成待校对手册；重复的候选认识先合成一份方法构思，原始来源全部关联。历史研究保留原来的时点，不能当作当前行情或当时已执行的计划。

工作台的“伙伴与成长”可以设置回答方式与关注点，查看已留下的反馈、采用过的整理、完成的复盘及值得回看的方法。对话后的“希望调整”能说明下次应如何改进。

## 实际协作

主伙伴理解任务后加载相关 Skill。简单收集和解释由主伙伴完成；需要多个角度时，使用 `collaborate` 邀请专职伙伴，各自实际执行一次独立模型与工具循环，再由主伙伴综合结果。

| 伙伴 | 技能 | 主要职责 |
| --- | --- | --- |
| 学习伙伴 | trading-classic-learning | 原意、解释、个人理解和边界 |
| 计划检查伙伴 | trading-plan-review | 判断依据、失败路径、风险和执行缺口 |
| 复盘伙伴 | trading-experience-review | 事前判断、实际执行、结果和可改进之处 |
| 体系回顾伙伴 | trading-environment-review | 支持、反例、环境解释和修订方向 |

个人使用版顺序执行，单次最多邀请三个伙伴；共享同一模型选择、工具注册表和当前资料，各有独立职责与提示词。专职伙伴只检查资料，不写入正文、不代确认纪律，也不继续委派。记录保留技能内容指纹、调用过的工具和完成状态，工具失败或超限显示仍有缺口。关闭资料归集时本轮协作记录也不写入业务数据库。

`vendor/runtime_core` 未修改。主会话继续使用原 QueryEngine；专职伙伴直接使用原 `queryLoop` 内循环，独立扩展负责角色配置、上下文和回执。没有另建一套推理引擎。

## 怎样扩展

1. 在 `skills/<名称>/SKILL.md` 增加工作流程；启动时统一发现。
2. 在 `config/capabilities.toml` 声明伙伴标识、职责、技能和工具名单。启动时检查技能、工具及重复标识，页面直接读取这份能力目录。
3. 确定性业务工具在 `trading_agent.service.Service.specs` 注册，网页接口和智能体共同调用业务实现；场景扩展工具加入核心注册表。计算逻辑不写进页面。

公共配置随发布包提供，私有密钥继续使用 `config/app.env`。增加伙伴和流程无需调整导航；新增专用交互工具需要按实际输入设计界面。

## 本版的自进化

每次请求由服务端重新构建 `cloud_learning`：主动设置的回答偏好、当前专题相关反馈、相关已复盘案例、已经采用的正文整理，以及来源变化或出现反例的回看提示。主伙伴与专职伙伴都读取这些实际积累，帮助后续回答减少重复、遵循偏好、检查旧经验的边界。

这是持续积累和校正协助方式。模型权重没有自行训练，技能文件没有自动改写，也没有后台行情监控。市场方法的有效性需要适用条件、正反例和实践证据；个人反馈“有帮助”不能证明交易方法盈利。重要纪律、风险边界及个人采用状态继续由用户审阅决定。

## 历史整理与可回查性

`KnowledgeCurator` 按已有记录和本工程经典目录创建有来源的专题、笔记和方法草稿。第一次新增前备份原数据库。稳定整理标识保证重复运行不复制已有条目，也不覆盖用户后续编辑。自动整理显示“历史整理 / 经典导读 · 待校对”，编辑后保留自己的版本；校对不等于正式采纳。

原始资料、事实、版本和已生效纪律保留。没有完整事前记录的历史研究不会补造为实践案例。公开目录的出处标注沿用现有核验范围，不声称本次重新联网核验。后续资料可在“伙伴与成长”中点击“整理新增资料”。

## 验证

自动测试覆盖真实核心双伙伴循环、共享读取、失败状态、禁止专职写入、不记录模式、反馈进入下一次模型请求、新增配置能力、技能跨目录公开参考、整理幂等及原始资料保留。真实模型验收使用临时库：

```sh
.venv/bin/python -m unittest discover -s tests -q
.venv/bin/python scripts/build_frontend.py --web-only
.venv/bin/python scripts/verify_model.py kimi --growth --collaboration
.venv/bin/python scripts/verify_model.py deepseek-flash --growth --collaboration
```

页面验收使用合成历史记录与已有公开经典，不把验收讨论、演示复盘或模型测试写进个人交易资料。
