覆盖现有九项工具：大趋势分析、图表与画线、资金参与判断、趋势与量价检查、放量后的结构观察、仓位与风险计算、A 股行情查询、持仓与交易台账、准则条件检查。

## 交互与口径

- 标题旁固定「? 帮助」，默认不显示说明。点击在当前侧栏打开帮助；返回、关闭帮助或 Escape 都回到原工具。
- 帮助分为怎么用、判断逻辑、怎么看结果、按需展开的计算细节与参数、使用边界。原意与实现参数分开；均量与中位量、复权口径、完成K线、转折延迟确认、截止日范围如实说明。
- 原工具保持挂载，仅隐藏操作区域。帮助打开不请求行情、不计算、不保存资料。展开状态只属于本次帮助阅读。
- 合并两项量价工具原来默认显示的长说明，保留结果证据、逐日轨迹与数据来源。
- 帮助入口及细节按钮提供语义、展开状态和键盘入口；开启帮助后焦点落在可返回的入口，Escape 返回并保持焦点。
- 新工具帮助统一维护在 frontend/src/domain/toolHelp.ts；ToolHelp.vue 统一呈现，ToolPanel.vue 统一装配。
