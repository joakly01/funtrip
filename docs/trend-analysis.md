# 大趋势分析

入口：交易体系 → 器·交易工具 → 大趋势分析。输入股票名称或代码，重名时先选择证券。

## 从判断到行动

1. 先看周线大方向：上涨趋势、盘整阶段、下跌趋势或方向待确认。
2. 再看日线位置：日线走强不直接等于大趋势反转；日线走弱也不自动否定周线方向。
3. 查看支持依据、结构分歧与前一确认高低点，随后查阅当前阶段的观察重点、准备条件、容易犯的错误与重评条件。
4. 点击“结合我的情况，检查计划”，把股票、行情截至时间、复权基准、判断依据和重评条件带入对话草稿，结合个人周期、持仓与已生效准则继续讨论。工具本身不记为交易，不自动修改纪律。

| 阶段 | 观察重点 | 计划准备 | 重评条件 |
| --- | --- | --- | --- |
| 上涨 | 回调能否守住确认低点，能否重新向上 | 等待回调企稳或突破确认；先核算损失范围 | 周线结构破坏、均线转弱或日线持续走低 |
| 盘整 | 区间边缘、突破能否维持 | 优先等待边缘或确认；按自己的已验证方法处理 | 越界后形成新高低点结构与一致方向 |
| 下跌 | 反弹是否受压，低点是否下移 | 空仓等待转折证据；持仓核对退出条件 | 低点抬高、高点突破且均线止跌转升 |
| 待确认 | 历史不足、周期冲突、复权或价格异常 | 补齐信息，等待结构与均线一致 | 新完成周线或核对后的可靠价格证据 |

这些内容是观察和制定计划的候选方法，不是自动下单信号。

## 数据与方法 v1

共享只读业务工具 `market_trend`；网页只读入口 `/api/tools/trend`。学习、计划、复盘、体系回顾伙伴均可调用。新增功能不修改 vendor 引擎。

- 请求最多640根已完成的**前复权日线**。来源返回多少就展示多少，不保证完整交易日历或固定覆盖年数。不混入分钟线、未完成日线或其他复权口径。
- 自日线聚合周线：首个自然周可能不完整，保守剔除；按获取时刻的上海日期剔除当前自然周。节假日周、停牌与历史缺失未用交易所日历核验。周线收盘时间与日线截至时间分别显示。
- 周线使用10/40周简单均线，40周均线与4根前比较；至少44根周线。日线使用20/120日均线，120日均线与10根前比较；至少130根日线。
- 在最近最多52周或120日窗口计算收盘线性回归方向、R²及14根简单ATR。高低点需要左右各两根K线严格确认，最新两根不参与确认，属于滞后观察，不是缠论笔或线段。
- 上涨：收盘 > 短均线 > 长均线；长均线变化 >0.5%，短均线斜率为正；回归净移动 >2ATR且R²≥0.35；确认结构不能是高低点均下降。下跌为对称条件。缺结构或结构分歧同时展示反证提醒。
- 盘整有独立条件：长均线变化绝对值≤1%，短均线变化绝对值≤2%，R²<0.25，有至少两组确认高点与低点且结构不一致向上/向下。“没确认上涨或下跌”不能自动归为盘整。
- 最近20根完成日线的变化辅助区分回调与反弹（±2%的观察阈值），不能覆盖周线大方向。
- 最近60根日线开盘相对前收盘跳变超过35%，暂停周线与整体定性，提醒先核对复权和价格。此检查不能发现所有除权或来源问题。
- 前复权历史随基准变化，参考价格要核对当前口径；保存获取日期作为来源报告的基准标记，不保证供应商因子已独立验证。图中均线用完整有效历史计算后截取展示窗口。
- 公共来源只返回原始日线、缺少前复权字段时，明确报错，不把原始日线冒充前复权。当前不能据此覆盖所有证券。

参数是本工具的透明观察规则，**未经收益回测**；不存在胜率、主力身份或涨跌预测。

思想参考：[StockCharts 道氏理论说明](https://chartschool.stockcharts.com/table-of-contents/market-analysis/dow-theory)中对主要趋势、次级波动和高低点的区分，以及[DecisionPoint 趋势模型](https://chartschool.stockcharts.com/table-of-contents/trading-strategies-and-models/decisionpoint-trend-model)对不同周期均线的说明。这里是单股观察规则，不冒充完整道氏理论的指数相互确认模型；阈值由工程自定义。

## 验收

自动测试覆盖上涨/盘整/下跌、平坦但无区间证据、短历史不借用日线结论、未完成数据与首尾周排除、异常跳变、未来与无效价格、确认端点、缺前复权不得替代、接口鉴权/证券候选/来源错误与只读调用。测试使用隔离目录；网页操作验收使用独立临时库与公开行情。
